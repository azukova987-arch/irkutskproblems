# Карта проблем Иркутска

Учебный проект — городской информационный портал для публикации и просмотра городских проблем.

## Возможности первой версии

- Просмотр демонстрационных обращений.
- Поиск по названию, описанию и адресу.
- Фильтрация по категории.
- Просмотр подробной информации.
- Добавление обращения через форму с проверкой полей.
- Выбор изображения для обращения.
- Демонстрационные отметки на схематичной карте.
- Адаптивный интерфейс для компьютера и телефона.

## Структура

- `index.html` — главная страница.
- `css/style.css` — стили.
- `js/main.js` — тестовые данные и логика интерфейса.
