# Карта проблем Иркутска

Учебный проект — городской информационный портал для публикации и просмотра городских проблем.

## Как запустить

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта.
3. Запустите `index.html` в браузере. Для удобной разработки можно использовать расширение Live Server в Visual Studio Code.

## Возможности первой версии

- Просмотр демонстрационных обращений.
- Поиск по названию, описанию и адресу.
- Фильтрация по категории.
- Просмотр подробной информации.
- Добавление обращения через форму с проверкой полей.
- Выбор изображения для обращения.
- Демонстрационные отметки на схематичной карте.
- Адаптивный интерфейс для компьютера и телефона.

## Структура

- `index.html` — главная страница.
- `css/style.css` — стили.
- `js/main.js` — тестовые данные и логика интерфейса.
- `pages/` — место для будущих отдельных страниц.
- `assets/images/` — место для изображений.

## Важно

Это первая клиентская версия. Обращения хранятся только в памяти страницы и исчезают после перезагрузки. Для общего хранения потребуется сервер и база данных.
